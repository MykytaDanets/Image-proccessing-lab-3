EDGE DETECTION - READY-TO-RUN PYTHON PROJECT
Use Python 3.11 or 3.12. Extract the complete folder first.
Install once: python -m pip install -r requirements.txt
Run: python project.py
Only edit the clearly marked PARAMETERS block near the top of project.py.
Use a new RUN_NAME for each run. Existing result folders are never overwritten.
Open results/<RUN_NAME>/photo_comparison.png and synthetic_comparison.png.
A photo edge count is NOT a quality score. Synthetic boundary rates use a 2-pixel tolerance.
run_experiments.py runs all seven prescribed experiments automatically, if desired.
Read the supplied project instructions for setup, parameters and questions.
No internet is used by the program. No GPU, live camera or Python programming knowledge is required.
